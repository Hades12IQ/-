## B. Findings

Severity: critical / major / minor. Category vocabulary as requested.

### B.1 Compile-risk (Swift 5 mode, `SWIFT_STRICT_CONCURRENCY=minimal`, default nonisolated)

Both stores are explicitly `@MainActor @Observable final class` (AgentStore 43–45, CodeStore 56–58); `CodeProjectRepository` is an `actor` (707); models/pointers/`CodePreviewBuilder`/`AgentArtifactWriter` are `nonisolated` value types. Views inherit `@MainActor` from `View.body`. `FirasCompletionCue` and `NotificationCoordinator` are `@MainActor` and are only awaited from the stores' main-actor tasks. Result: **no isolation change is required in this group for the Swift-5 switch**; nothing in these eight files depended on default-MainActor inference. Two things to know so nobody wastes a CI cycle:

1. **`nonisolated` on type declarations** (`nonisolated struct …`, `private nonisolated enum …`, AgentStore 4/28/33/38/458, AgentModels 3/23/33/45/52/66/74/82/92/102/116/120, CodeModels 3/9/47, CodeStore 4/26/32/764) is SE-0449, available from the Swift 6.1 compiler in every language mode. Xcode 26 ships ≥ 6.2, so it compiles under `SWIFT_VERSION = 5.0`. Under default-nonisolated it is redundant; expect no warning. — minor / compile-risk, no action.
2. `FirasAPI.init(configuration:)` is `@MainActor` (FirasAPI 10–13) and is the default argument of `AgentStore.init(api:)` / `CodeStore.init(api:)` (AgentStore 65–73, CodeStore 84–94). Default arguments evaluate in the caller; the only callers (`FirasAIApp.init`, `App` is `@MainActor`) pass `api` explicitly anyway. — minor / compile-risk, no action.

Everything else used is inside the iOS 18 SDK: `containerRelativeFrame` (17), `TextField(text:prompt:axis:label:)` (16), `.clipShape(.rect(cornerRadius:))` (17), `Label(LocalizedStringResource, systemImage:)` (16), `ShareLink` (16), switch-expressions (Swift 5.9). `String(format: "%02d:%02d", Int, Int)` (AgentScreen 602, CodeScreen 656) works but `%ld` is the correct conversion for `Int`.

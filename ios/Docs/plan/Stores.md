# Plan — `Stores/` (SessionStore Batch 0; the rest Batch 1, one owner per store)

Interfaces: `INTERFACES.md` → Stores/. Every store: `@MainActor @Observable final class`, constructed
only by `AppEnvironment`, exposes `applicationDidBecomeActive()` where relevant, maps errors through
`ErrorPresenter` and surfaces them via `ToastCenter` / `Router.showSignUp` / a per-conversation strip.
Delete `Stores/MediaStudioStore.swift` (replaced by `MediaStore.swift`).

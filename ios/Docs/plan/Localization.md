# Plan — `Localization/`

Interfaces: `INTERFACES.md` → Localization/. No `.xcstrings`, no `LocalizedStringKey` anywhere in
app code (`InfoPlist.strings` stays). Arabic copy is pasted **verbatim** from the web STR tables the
reports cite; `[new]` copy comes from `design-brief.md`. One `extension Strings { enum X { … } }` per
file; feature files are owned by the feature's Batch 1 owner.

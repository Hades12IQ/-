## التحقق

أضيفت حالات اختبار APIClient باستخدام URLProtocol للنقل الجزئي، استعادة التأكيد، أخطاء الملكية، الرفع، الملفات المكتبية، أومنكس وحفظ بياناته. يشغّل بناء GitHub هذه الحالات داخل فحص الآيفون على المحاكي، إضافة إلى اختبارات الرياضيات وتصدير PDF السابقة. يتضمن اختبار PowerPoint فحص ملفات ZIP/XML الفعلية للشرائح وملاحظاتها.

اختبار audit-rendering المحلي ناجح. سكربت audit-products القديم لا يعمل مع شجرة التطبيق الحالية لأنه يطلب AgentStrings.swift غير الموجود؛ لا يُستخدم بديلاً عن بناء Xcode وفحص المحاكي. نتيجة البناء المنشور هي المرجع النهائي لصلاحية IPA.

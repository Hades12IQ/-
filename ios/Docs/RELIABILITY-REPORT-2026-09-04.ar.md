## ملاحظات الأمان والخصوصية

1. **عزل مشاريع Code بين الحسابات:** كان الكاش المحلي مشتركاً، ويمكن أن يُعرض قبل التحقق من إذن الحساب الجديد. صار الكاش مرتبطاً بصاحب الحساب، وتُمسح حالة العرض عند تبديل الهوية. الملفات القديمة محفوظة، ولا تُنقل تلقائياً إلى حساب مختلف.
2. **سباق أثناء الطلبات:** كان إكمال طلب Code قد يستخدم المشروع أو الحساب المفتوح بعد الانتظار. الطلبات مرتبطة الآن بهوية الحساب والمشروع عند بدايتها، ولا تُكتب نتيجة حساب سابق داخل الحساب الحالي.
3. **السياق القادم من المستودعات:** فحص أسماء الملفات والمحتوى يقلل إرسال ملفات مفاتيح أو بيانات اعتماد واضحة إلى النموذج تلقائياً. هذا لا يعادل كاشف أسرار شاملاً لكل صيغة ممكنة.
4. **HTML داخل المستندات:** سياسة محتوى تعزل طلبات الشبكة الفرعية وتستخدم أصول الخطوط والرياضيات المحلية. المستند غير الموثوق لا يحتاج جلسة مستخدم أو اتصالاً خارجياً لكي يُطبع.
5. **حفظ الرياضيات:** الكاش محمي بحماية ملفات iOS ومستثنى من النسخ الاحتياطي، ولا يكتب معادلات المحادثات المؤقتة. يُنظّف عبر مسار تنظيف بيانات العرض الموجود عند تبديل الحساب أو حذف البيانات.
6. **النشر المتزامن:** بناء الفروع المختلفة كان يستطيع استبدال نفس إصدار `ios-latest` بالتوازي؛ صار ناشرو IPA متسلسلين.
7. **تصدير مشروع باسم `..`:** كان الاسم الخاص قادراً على توجيه ضغط ZIP إلى مجلد الملفات المؤقتة الأب. تُستبدل الأسماء النقطية باسم آمن، مع حماية ملفات التصدير محلياً. أضيف فحص فعلي لهذه الأسماء في المحاكي.
8. **تبديل الحساب أثناء التحضير والحفظ:** أضيف تثبيت هوية صاحب الطلب قبل انتظار الشبكة أو القرص، ثم فحصها قبل الطلب التالي أو عرض النتيجة. يشمل ذلك تحضير الوسائط والترجمة وإنشاء المحادثة وحفظها وبدء ومتابعة أعمال الخلفية. الأعمال التي قبلها الخادم تبقى مرتبطة بصاحبها لتُستأنف عند رجوعه.
9. **فهرس الوسائط المحلي:** كان الترشيح يسمح بعناصر بلا صاحب، وكانت كتابة القائمة المصفّاة قادرة على استبدال فهرس الحسابات الأخرى. صار لكل حساب فهرسه المستقل، مع إبقاء الفهرس القديم للقراءة الانتقالية دون حذف سجل حساب آخر.

هذه مراجعة للكود الأصلي ومساراته المرتبطة بالمشاكل المطلوبة، وليست اختبار اختراق شاملاً للخادم. لم تُستخدم ملفات طلاب أو مفاتيح مزودين داخل بيانات الاختبار.

## التحقق

نجحت فحوص JavaScript المحلية لمحرك KaTeX المرفق: ثماني حالات رياضيات وكيمياء، وخمس حالات حدود لمحددات الرياضيات داخل المستندات. نجحت فحوص صياغة workflow والسكربتات والحفاظ على ترميز UTF-8.

اختبار Xcode والمحاكي في GitHub يشمل إنشاء PDF عربي طويل بجدول من 100 سطر، التحقق من عدد الصفحات ومقاس الورق وآخر فقرة، المعادلات والكيمياء، وإعادة قراءة المعادلات المحفوظة من القرص. تُحفظ صور صفحات PDF ولقطة من المحاكي مع أدلة الإصدار. نتيجة التنفيذ النهائية موثقة مع رابط البناء عند تسليم الإصدار.

يلزم اختبار تفاعلي على الآيفون الحقيقي لتأكيد إحساس التمرير مع كيبورد الجهاز، مقابض تحديد النص، ومسارات الصوت عبر السماعة والبلوتوث. اختبارات المحاكي لا تتصل بمزودي توليد الوسائط ولا تثبت جودة كل إجابة يولّدها النموذج. دعم KaTeX وmhchem لا يعني تشغيل جميع حزم TeX الموجودة. تعليمات Code وأدواته جرى تحسينها؛ لم يُدرَّب نموذج أساس جديد، ولا يُدّعى تشغيل مترجمات أو اختبارات مشاريع مولّدة إذا لم تتوفر تلك الأدوات.
